# Scoring Philosophy

## Universal Principles

### Score Range: 0-100
- **90-100**: Exceptional, rare
- **80-89**: Very good, above average
- **70-79**: Good, solid choice
- **60-69**: Fair, acceptable with caveats
- **50-59**: Below average, significant concerns
- **< 50**: Poor, not recommended

### Confidence Levels
- **High**: Based on comprehensive, reliable data
- **Medium**: Based on partial data or estimates
- **Low**: Based on limited or uncertain data

### Always Include
1. Overall score
2. Confidence level
3. Key strengths (2-3 bullet points)
4. Key concerns (2-3 bullet points)
5. Reasoning (2-3 sentences)
